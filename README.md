# ⚡ 자동 전기회로 설계 도우미

파이썬을 이용하여 사용자가 보유한 저항(R), 인덕터(L), 커패시터(C)를 조합하고, 원하는 전기적 목표에 가장 가까운 회로를 자동으로 탐색하고 추천하는 프로그램입니다.

## 📌 프로젝트 소개

일반적인 전기회로 계산기는 사용자가 직접 회로를 구성한 뒤 계산 결과를 확인하는 방식입니다.

이 프로젝트는 여기서 한 단계 더 나아가, 사용자가 가지고 있는 부품과 원하는 목표값을 입력하면 프로그램이 여러 회로 구성을 탐색하고 가장 적합한 회로를 추천하도록 제작했습니다.

## ✨ 주요 기능

### 1. 부품 입력
- 저항(R) 개수 및 저항값 입력
- 인덕터(L) 개수 및 인덕턴스 입력
- 커패시터(C) 개수 및 정전용량 입력
- 입력한 부품 중 필요한 부품만 선택하여 회로 구성

### 2. 설계 목표 선택

다음 세 가지 목표 중 하나를 선택할 수 있습니다.

- **목표 전류:** 원하는 전류에 가장 가까운 회로 탐색
- **목표 임피던스:** 원하는 임피던스에 가장 가까운 회로 탐색
- **목표 공진 주파수:** 원하는 공진 주파수에 가장 가까운 회로 탐색

### 3. 자동 회로 탐색
- 직렬회로
- 병렬회로
- 직병렬회로

여러 회로 후보를 생성하고 계산 결과를 비교합니다.

### 4. 회로 분석
- 합성 임피던스 계산
- 전체 전류 계산
- 공진 주파수 탐색
- 목표값과의 오차 계산

### 5. 회로도 출력

추천된 회로의 부품 배치를 터미널에 문자 형태로 출력합니다.

### 6. 공학적 접두어 표시

계산 결과를 다음과 같은 공학적 접두어로 표시합니다.

- k (킬로)
- M (메가)
- m (밀리)
- µ (마이크로)
- n (나노)
- p (피코)

- 언어: Python
- 실행 환경: Python 3
- 인터페이스: 터미널
- 외부 라이브러리: 사용하지 않음

## 📝 사용 방법

프로그램 실행 후 다음 순서로 진행합니다.

1. 전압 입력
2. 설계 목표 선택
3. 목표값 입력
4. 저항, 인덕터, 커패시터 개수 입력
5. 각 부품의 값 입력
6. 자동 회로 탐색
7. 추천 회로와 계산 결과 확인

### 부품 입력 단위

| 부품 | 입력 단위 | 입력 예시 |
|---|---|---|
| 저항(R) | Ω | 100 |
| 인덕터(L) | H | 0.01 |
| 커패시터(C) | F | 0.0001 |

## ⚙️ 현재 구현 범위 및 제한 사항

- 저항, 인덕터, 커패시터는 각각 최대 5개까지 입력할 수 있습니다.
- 한 회로에서 최대 8개 부품까지 탐색합니다.
- 직병렬회로는 두 개의 직렬 가지가 병렬로 연결되는 구조까지 탐색합니다.
- 공진 주파수는 1Hz부터 1MHz 범위에서 수치적으로 탐색합니다.
- 모든 가능한 회로 구조와 부품 배열을 탐색하는 것은 아닙니다.
- 실제 부품의 허용 오차, 내부 저항 및 기생 성분은 고려하지 않습니다.

## 🎯 프로젝트 목표

단순히 회로의 계산 결과를 알려주는 것을 넘어, 사용자가 보유한 부품을 활용하여 원하는 전기적 특성에 가까운 회로 구성을 자동으로 찾아주는 프로그램을 만드는 것이 목표입니다.

앞으로 회로 탐색 알고리즘을 개선하고, 더 다양한 회로 구조를 지원하는 방향으로 발전시킬 예정입니다.
